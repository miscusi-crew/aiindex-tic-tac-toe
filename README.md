# Tic-Tac-Toe

Play the computer (good luck on Unbeatable) or a friend.

Three in a row wins. Play against the computer on Easy or Unbeatable, or pass the device to a friend.

- Keeps score until you reset it
- Unbeatable never loses: the best you can get is a draw

## Run it

Open `app/index.html` in a browser. There's no build step and no dependencies: plain HTML, CSS and JavaScript.

On AI Index it runs in the browser with **Run here** (Offline). `aiindex.json` tells AI Index which
folder to serve; its token links this repo to the listing.
